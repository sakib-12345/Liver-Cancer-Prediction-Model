# 🧠 Trained Model

This folder contains the trained **EfficientNetV2-S** model used for the liver MRI multi-class classification project.

### Model
- Architecture: EfficientNetV2-S
- Framework: PyTorch
- Classes: 5
- Input Size: 224×224
- Training: Transfer Learning

The trained model is stored as `best_model.pth`.

> ⚠️ This model is an experimental research/educational model and is not intended for clinical diagnosis.
