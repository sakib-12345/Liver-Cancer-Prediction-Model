# 🗂️ Dataset

This project uses the **Liver Cancer Multiclass Dataset** from Kaggle.

### Classes
- Healthy
- Angiosarcoma
- Cholangiocarcinoma
- Hemangioma
- Hepatocellular Carcinoma

The original dataset is not included in this repository due to its size.

**Dataset:**  
https://www.kaggle.com/datasets/ucimachinelearning/liver-cancer-multiclass-dataset

Please refer to the original Kaggle page for dataset licensing and usage information.
